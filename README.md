# 大戶籌碼追蹤（集保戶股權分散表）

網站：https://c59201.github.io/chip-tracker/

每週自動抓取集保結算所的「集保戶股權分散表」，追蹤全體上市櫃股票的
**400張以上大戶**、**1000張以上大戶** 與 **散戶（≤50張）** 持股變化，篩選出大戶籌碼持續增加、散戶持續減少的標的。
網站用 GitHub Pages 免費架設，GitHub Actions 每週六自動更新，不需要開電腦。

## 網站功能

| 分頁 | 條件（皆可在網頁上調整） |
|---|---|
| 連續增加 | 大戶持股比例連續 N 週上升（400／1000／任一／兩者）＋ 散戶持股比例或人數連續 N 週下降 |
| 累積幅度 | 近 M 週 400張持股增加 ≥ X 個百分點、1000張增加 ≥ Y、散戶減少 ≥ Z |
| 單週跳升 | 最新一週 400張 或 1000張 持股單週增加 ≥ 門檻，可再要求為近 12 週平均波動的 K 倍 |
| 多重符合 | 同時符合上面兩項以上 |
| 自選 | 點 ☆ 加入（存在瀏覽器裡） |
| 全部 | 所有股票，可搜尋、排序 |

另有：市場／股價／股東數篩選、欄位排序、匯出 CSV、個股明細（6 張走勢圖＋逐週表格＋神秘金字塔連結）。

## 定義

- 400張以上＝持股分級 12–15（400,001 股以上）
- 1000張以上＝持股分級 15（1,000,001 股以上）
- 散戶＝持股分級 1–8（50 張以下），可在 `scripts/common.py` 的 `RETAIL_LEVELS` 修改
- 持股比例＝該分級股數 ÷ 集保庫存總股數

## 自動更新與回補

- 每週六上午 10 點（台北時間）自動更新，週日再檢查一次（Actions →「每週更新籌碼資料」，也可手動 Run workflow）。
- 集保開放資料只提供最新一週。要補歷史週次，到 Actions 執行「回補歷史資料（手動）」，週數填 8。
  全市場每週約需 30–40 分鐘，一次跑不完會自動存檔，再按一次 Run workflow 就會接續。

## 檔案結構

```
scripts/fetch_weekly.py   抓最新一週集保資料、股票名稱產業、收盤價
scripts/backfill.py       從集保查詢頁回補歷史週次（可續跑、刻意放慢速度）
scripts/build_summary.py  彙整成 site/data/summary.json（預設保留 26 週）
scripts/common.py         分級定義與共用函式
site/                     網站（index.html、app.js、style.css）
data/raw/                 每週原始資料（YYYYMMDD.csv.gz）
.github/workflows/        每週排程與手動回補
```

## 資料來源與注意事項

- [集保結算所 開放資料 1-5 集保戶股權分散表](https://opendata.tdcc.com.tw/getOD.ashx?id=1-5)、
  [集保戶股權分散表查詢](https://www.tdcc.com.tw/portal/zh/smWeb/qryStock)、證交所 ISIN 代碼表、證交所／櫃買中心 OpenAPI。
- 回補腳本依賴集保查詢頁的網頁格式，若集保改版可能需要調整 `scripts/backfill.py`；每週自動更新使用的是穩定的開放資料 CSV。
- 減資、增資、合併等會改變總股數，可能造成比例變化，看個股明細時請留意。
- 僅供研究參考，非投資建議。
